# i18n — Internacionalización

## Setup

El proyecto usa `@ngx-translate/core` con archivos JSON por idioma:

```
src/assets/i18n/
├── es.json    ← Español (default)
├── en.json    ← English
└── pt.json    ← Português
```

Configurado en `app.config.ts`:

```typescript
...provideTranslateHttpLoader({
  prefix: './assets/i18n/',
  suffix: '.json'
})
```

## Uso en Templates

Siempre usa el pipe `translate`, nunca texto hardcodeado:

```html
<!-- ✅ -->
<h1>{{ 'sanidad.triaje.title' | translate }}</h1>
<button>{{ 'shared.buttons.save' | translate }}</button>

<!-- ❌ -->
<h1>Triaje</h1>
<button>Guardar</button>
```

## Uso en TypeScript

```typescript
import { inject } from '@angular/core';
import { TranslateService } from '@ngx-translate/core';

@Component({ ... })
export class MiComponente {
  private translate = inject(TranslateService);

  mostrarMensaje() {
    const msg = this.translate.instant('sanidad.triaje.success');
    console.log(msg);
  }
}
```

## Estructura de Keys

```
{modulo}.{seccion}.{elemento}

Ejemplo:
{
  "sanidad": {
    "triaje": {
      "title": "Triaje",
      "subtitle": "Gestión de triaje animal",
      "form": {
        "nombre": "Nombre",
        "severidad": "Severidad",
        "submit": "Guardar triaje"
      },
      "list": {
        "empty": "No hay triajes registrados",
        "headers": {
          "animal": "Animal",
          "fecha": "Fecha",
          "estado": "Estado"
        }
      }
    }
  },
  "shared": {
    "buttons": {
      "save": "Guardar",
      "cancel": "Cancelar",
      "delete": "Eliminar",
      "new": "Nuevo"
    },
    "messages": {
      "loading": "Cargando...",
      "error": "Error al cargar datos",
      "noData": "No hay datos disponibles"
    }
  }
}
```

## Agregar un Nuevo Idioma

1. Crear el archivo JSON: `assets/i18n/{lang}.json`
2. Copiar la estructura del `es.json`
3. Traducir todos los valores
4. Agregar el idioma al `TranslateService` si es necesario

## Cambiar Idioma

```typescript
private translate = inject(TranslateService);

// Cambiar a inglés
this.translate.use('en');

// Cambiar a portugués
this.translate.use('pt');
```

## Reglas

- **Nunca** texto hardcodeado en templates
- **Nunca** texto hardcodeado en TypeScript (mensajes, labels, etc.)
- **Sí** usar keys descriptivas y anidadas por módulo
- **Sí** mantener los 3 archivos JSON sincronizados (agregar key en los 3 idiomas)
- **Sí** usar `shared.*` para textos reutilizables entre módulos
